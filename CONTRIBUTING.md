# Contributing to Peacock

Contributions of all kinds are welcome: bug reports, docs, and code.

## How to contribute

1. Fork the repo and create a branch from `main`.
2. Make your change, keeping it focused on one thing.
3. Commit with a sign-off (see below).
4. Open a pull request describing what changed and why.

For larger changes, open an issue first so we can agree on the approach.

## Sign your commits (DCO)

Peacock uses the [Developer Certificate of Origin](DCO) instead of a CLA.
Add a `Signed-off-by` line to every commit by using `-s`:

```sh
git commit -s -m "Fix outline for nested classes"
```

This certifies you have the right to submit the code under the project's
[MIT license](LICENSE). Forgot to sign? Fix it with
`git commit --amend -s` (last commit) or `git rebase --signoff main`.

## Reviews

`.github/CODEOWNERS` automatically requests review from the maintainer.
